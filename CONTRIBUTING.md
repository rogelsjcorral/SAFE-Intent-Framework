# Contributing
Thanks for helping improve S.A.F.E.

## How to contribute
1. Open an Issue for questions, missing failure modes, or suggested
   edits.
2. Fork the repo and submit a Pull Request for changes.

## Guidelines
- Keep PRs focused: one topic per PR.
- If you reference an external concept, paper, standard, or incident,
  add a citation in the document.
- Do not include secrets, tokens, or real credentials in examples or
  logs.
- Prefer clear, testable requirements wording (MUST, SHOULD, MAY).

## Suggested areas
- Failure modes and edge cases for privileged automation
- Confirmation thresholds for large target sets
- Integration profiles and wrapper examples
- MER schema refinements
