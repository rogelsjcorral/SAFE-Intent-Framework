# The S.A.F.E. Intent Framework
S.A.F.E. is an RFC-style proposal for validated intent in AI-assisted
administrative automation, focused on privileged environments where a
script can “succeed” while doing the wrong thing.

## Status
Request for Comments (RFC-style draft). Feedback welcome via Issues and
Pull Requests.
