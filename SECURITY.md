# Security Policy

The SAFE Intent Framework repository contains a research
specification and a proof-of-concept implementation.

If you discover a security issue related to the reference
implementation or example scripts, please report it privately.

Contact:
rogelsjcorral@gmail.com

Please do not open public issues for security vulnerabilities
until the issue has been reviewed.

Note:
The reference wrapper is a proof-of-concept and is not intended
for production environments.
